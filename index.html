002AI 之后，设计师还剩什么？+

执行越来越便宜，但 framing、prioritization 与复杂情境中的判断并没有自动变得容易。

SHIFT → 判断比产出更稀缺。
003必须当“设计程序猿”吗？+

代码与原型的边界变薄，但新的技能并不自动带来决策权。

SHIFT → 从 skill 转向 ownership。
004AI Engineer ↔ Product Design+

设计和工程开始双向靠近，关键在于谁能定义问题、负责取舍。

OPEN → 靠近实现，不等于掌控决定。
005当 AI 做决定，设计师还决定什么？+

设计师、产品经理和工程师从不同视角追问 AI 时代的责任归属。

SHIFT → 从角色边界到决策责任。
006设计师在工作中如何 Vibe Coding？+

讨论进入真实流程：哪些环节更快，哪些 edge cases 让全局更慢。

PATTERN → 单点效率不等于系统效率。
007Vibe Coding at Work — Part 02+

Prompt、Context、Skill、MCP 与多人协作，把问题引向 production 的责任与维护。

SHIFT → 瓶颈从 generation 转向 integration。
008AI-native：产品升级，还是组织重构？+

对照 AI-native 从 0 到 1、成熟 SaaS 转型、大组织局部重构，以及从 AI-enabled 出发的不同路径。

DISCUSSION → AI-native 在不同组织里意味着不同的产品、流程与责任变化。
